# social-media-impact-analysis-python
A Python data analysis project exploring the relationship between social media usage, sleep, stress, and academic performance among students.
# Social Media Impact on Students' Life

## 1. Introduction
This project analyzes social media usage and its relationship with students' sleep, stress, mental health, and academic performance using Python.

## 2. Objectives
- Analyze students' daily social media usage.
- Explore the relationship between social media usage and sleep duration.
- Understand patterns in stress levels and academic performance.
- Visualize important findings using charts.

## 3. Dataset
The dataset contains information about 4,500 students and 16 columns, including age, gender, social media platform, daily usage hours, sleep duration, stress score, mental health index, and academic GPA.

## 4. Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## 5. Project Workflow
1. Imported the dataset using Pandas.
2. Explored the data using head(), info(), describe(), and shape.
3. Checked and handled missing values.
4. Checked for duplicate records.
5. Performed data analysis using Pandas and NumPy.
6. Created visualizations using Matplotlib and Seaborn.

## 6. Visualizations
- Count plot: Social media platform usage.
- Scatter plot: Daily social media usage vs. sleep duration.
- Histogram: Distribution of students' GPA.
- Box plot: GPA by overall social media impact.

## 7. Key Findings
- Instagram was the most commonly used platform in the dataset.
- Average daily social media usage was approximately 5.30 hours.
- Average sleep duration was approximately 6.70 hours.
- The dataset showed different patterns in GPA across overall impact categories.

These findings describe patterns in the dataset and do not establish cause-and-effect relationships.

## 8. Conclusion
This project provided practical experience in data cleaning, exploratory data analysis (EDA), numerical analysis, and data visualization using Python. It helped explore patterns in students' social media usage, sleep, stress, and academic performance.
